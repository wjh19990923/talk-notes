版本化的搜索：过去的网络

Ryan Ahern 讲解了 Exa Snapshot 如何让过去的网络搜索可用于检验预测信号——以及为什么历史截止时间只是一次可靠回测的一部分。

Ahern 讲解一张图：对比实时的收购搜索结果与公告发布之前的搜索结果。

01

当智能体来搜索时的搜索质量和成本

A search agent can keep trying after a person might give up: it can describe a request in detail, run several queries and explore different leads before answering. Ryan Ahern, a forward deployed engineer at Exa, starts there because each additional search makes retrieval quality and cost part of the agent’s overall task. Exa supplies search infrastructure including crawling, an index, an embedding model and retrieval.

The value of a result depends on what happens after the tool call. Useful retrieval can reduce repeated calls and help an agent stay on course; irrelevant material can send it in the wrong direction. Ahern says Exa developed a benchmark intended to assess search tools separately from the models that call them, since model and retrieval performance can otherwise be confounded.

Cost also includes the tokens sent back to the model. Dynamic Highlights selects relevant snippets across search results instead of returning full pages. Ahern reports higher-quality results with 95% fewer tokens than full-page text; that is Exa’s reported comparison, and he does not give its evaluation conditions here. At the other end of the latency range, he describes Exa Agent Ultra as combining the search harness with an agent harness for long-running research.

02

搜索答案出现之前可用的信息

Exa Snapshot uses versions captured during freshness checks to offer two operations: retrieve a known URL at or before a chosen date, or search for results available at or before that date. Ahern describes more than 400 billion snapshots. In his example, a slide compares an October 1 snapshot search with a later live search: the earlier reporting discussed an approximately $70 billion annualized OpenAI revenue run rate, while later reporting put a net figure closer to $50 billion after accounting for cloud-provider pass-throughs. These are the figures and accounting explanation presented in the talk.

The useful question is whether an agent could have found a clue before the discrepancy became widely discussed. Ahern suggests looking for an accounting footnote in an SEC filing or earlier reporting from another source. Those are possible leads, not findings established in the example. A historical search makes the question testable against captured material; it does not establish that every page available at the time was captured.

The acquisition example makes the leakage problem clearer. After a deal is announced, a live search can simply return the announcement. To test a predictor, search instead at one day, seven days and one month before the announcement, then compare the predictions with what actually happened. Ahern proposes building a set of cases and checking performance on a holdout to see whether the feature generalizes beyond the examples used to develop it.

03

把历史搜索放进预测系统的三种方式

Ahern describes three designs, distinguished by what turns web information into a prediction:

- Structured signals for an existing model: Extract historical software prices, sentiment or site terms from unstructured pages, then turn them into an array of inputs for an existing model. A price page may no longer show its earlier price, and sentiment has to be associated with when it appeared. - An agentic feature for an existing model: An agent runs multiple searches, follows different leads and condenses the findings into a structured feature. The traditional model still makes the prediction. - An agent-managed prediction: An agent coordinates the wider process, potentially using internal knowledge, data feeds and web search. Historical web retrieval controls one source of information available to that process.

For the middle design, consider an adverse-media scan before a company enters a portfolio. The agent searches for relevant coverage and compresses what it finds into a feature for the existing model. Snapshot lets a team ask what that scan would have produced a month before a decision, or when a company entered the portfolio four months earlier, and compare it with subsequent outcomes and the existing process. The point is to measure whether adding the feature helps, rather than assume that more search improves the model.

In an agent-managed acquisition prediction, the dated web tool helps prevent the easy failure: a search finds the later acquisition announcement and the agent presents the already-known outcome as a prediction. That cutoff controls the web-search input; other data feeds, internal sources and the agent’s own knowledge also matter when evaluating the whole system.

04

一个高分特征可能把答案背了下来

At a Snapshot workshop on acquisition prediction, one participant’s relatively high-scoring feature set included three questions: had an investor or significant shareholder publicly supported a sale within the past year; was the company’s share price at least 60% below its high over the previous five years; and was the company named Dominion? The first two describe circumstances that might recur. The company-name check can instead fit a particular example in the training data.

A historical cutoff prevents a search from returning a later announcement, but it does not by itself prove that a feature generalizes. Evaluations need cases held apart from feature development to expose shortcuts like the name check. Ahern’s practical contrast is with testing only in production: waiting for new acquisitions and revising feature descriptions in real time could take months.

Semantic search also lets a team propose more intricate features: for example, whether adverse media exists about venture-capital partners who appeared on the AI Engineer podcast and said something negative about it. The specificity makes the feature expressible; a backtest still has to determine whether it predicts anything useful. That is the closing test for a risk model or agentic process: does the added web feature improve the decision?

要点总结

  • Snapshot retrieves captured URL versions or search results at or before a chosen date, making historical web signals available for backtesting.
  • A dated search can keep a later acquisition announcement out of the web result, while other inputs and the agent’s knowledge still need attention.
  • Historical web data can enrich an existing model, supply an agent-generated feature, or support an agent managing the prediction itself.
  • A holdout helps distinguish a reusable signal from a shortcut such as checking a company’s name.
