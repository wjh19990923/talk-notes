一家银行自建了编程智能体，结果一飞冲天

Felippe Felisola Caso 和 Francesco Galletta 讲解了 Monzo 现有的平台如何把一个 Slack 表情回应，变成了一个可复用于编程、事故处理和数据质量的智能体。

标题幻灯片介绍了演讲的核心主题。

01

从一个 Slack 表情回应到一位远程队友

Monzo’s engineering teams maintain more than 3,000 backend services, around 13,000 data warehouse models and dozens of machine-learning predictors, including systems involved in credit and financial crime. That breadth gives a coding agent plenty to navigate—and makes access to the right internal context valuable. 0:12

Felippe Felisola Caso and Francesco Galletta trace Agent Chip’s rise to a Slack channel that went viral in January 2026. React to a message with its emoji, and the message becomes a prompt. The agent grew into an always-available teammate: people can mention it to ask about architecture, request a code review or assign it a Linear ticket. 1:43

At the time of the talk, the speakers report that Agent Chip authors over 10% of merged pull requests across technology teams and runs more than 1,800 tasks a day. Business users have also begun using it for questions and queries. These are adoption and activity figures; they do not by themselves measure the quality of the changes or the time saved. 2:47

02

表情符号背后的倍增效应

The speakers’ other expansion of LLM is “lots of little multipliers.” The Slack interaction looks simple because Monzo already had alerting, monitoring, third-party integrations, staging, queues, deployment and database abstractions. Those capabilities gave the team pieces it could assemble instead of building every operational dependency for the agent from scratch. 3:37

One of the earliest agent-specific pieces was an MCP gateway, built before the remote Agent Chip existed to support local coding agents. Monzo put internal services, tools and knowledge sources behind an MCP server. The server selects what agents can access and manages authentication and authorization for different agents. That gives the model useful context through a controlled interface, while keeping the choice of exposed capabilities in deterministic software. 5:06

03

给智能体在沙箱里工作的空间

Monzo then built an orchestration system for remote agents. It triggers agents running in a sandbox in an isolated namespace and reads information from them. The goal is to give nondeterministic agent behavior room to work while separating it from production infrastructure—a particularly consequential decision for a regulated bank. 6:06

How do the controls fit around an agent run? Multiple pods can start sandboxes in the isolated namespace. The agent image defines the environment and command-line tools available to it, with authentication and authorization supplied through the gateway. A proxy permits selected outbound connections, including access to repositories. Inside those controls, the agent decides what to do. The separation lets Monzo choose both the internal capabilities and external destinations a run can reach. 7:06

The gateway and orchestration system together make Agent Chip a building block. Slack, GitHub and Linear can connect to it, as can Monzo services. Engineers can use a local coding assistant for some work while delegating other tasks to remote agents; routine work can proceed without someone watching every step. The speakers describe a greater breadth and volume of tasks, though they do not quantify that change. 8:37

04

调查事故和数据问题

When an incident is triggered, Agent Chip joins its channel and starts investigating. What can it bring together for the people responding? Through MCP it can inspect logs and traces, connect to the affected service and examine its code. The intended output is high-signal help, not a stream of live speculation; humans control how much support the agent provides. 10:07

In Slack ask channels, squads request context from other squads about services, products or roadmaps. Agent Chip can use internal knowledge sources to draft a response for a human to use. If the answer is sufficient, it may resolve the ask itself; if it needs more context, it can ask for it and bring a human in. 10:37

Agent Chip on call applies the same building block to data quality in two ways:

- Reactive: It observes failures and automatically starts an investigation to triage data-quality alerts. - Proactive: It watches backend changes and identifies potential effects on data before the next batch processes it.

The second path moves the investigation earlier; the talk does not establish how often its warnings prevent errors. 11:37

05

让非专业人员也能发起一次变更

The Slack entry point also lowers the barrier for people outside engineering. A non-specialist can turn product feedback, an idea or a discussion into an Agent Chip request and receive a working draft tested in staging. An engineer then reviews the change and handles proper deployment. The contribution begins closer to the person with the idea, while engineering review remains part of the path to production. 12:07

06

随着模型变化保持平台有用

Why maintain an in-house agent as outside products improve? The speakers value Agent Chip as a composable part of Monzo’s platform: new uses can connect to existing security and backend capabilities. They also describe the platform as provider-agnostic, with the model in the agent box replaceable so Monzo can choose one suited to a task. 12:57

The next ambition is a wider development window: draft backend and app changes, test in staging, cover data tests and potentially extend to predictors. The speakers present fuller end-to-end remote work as a direction, not a completed capability. They are not committed to Agent Chip forever, but see lasting value in the platform pieces that make new uses possible. 14:28

要点总结

  • 一个简单的 Slack 表情回应之所以能很快变得有用，是因为 Agent Chip 可以建立在现有的预发布、部署、监控和集成能力之上。
  • MCP 网关控制对内部工具和知识的访问；沙箱、定义好的工具和选定的出站规则约束远程智能体的运行。
  • 同一套智能体基础设施支撑事故调查、小组的问题，以及被动和主动的数据质量工作。
  • 非专业人员可以发起分阶段的修改，而工程师仍负责审查和部署。
  • We Mapped 115 Microservices for Our Coding Agents — Kamalakannan Nandagopal, Postman —— 一种互补的方法，在大量服务之间为编程智能体提供上下文。
  • From Vibes to Production: Evaluating and Shipping AI Agents That Work 101 — Laurie Voss, Arize AI —— 关于检查 trace 和评估智能体行为的实践配套。
