Bash 就是你所需要的一切

幻灯片原文
Shihipar frames Bash as a general form of code mode: agents can save results and memory to files, generate scripts, and combine Unix commands with existing software.

[15:30](https://www.youtube.com/watch?v=TqC1qOfiVcQ&t=930s) [Slide lists ways Bash can store results and memory, run generated scripts, and compose existing tools.](https://assets.ai.engineer/sites/aiecode2025/sha256/c3cdecc985ce27603c285734b2401ea25ff3cc1ebfa05f8b615291fdcf31c31e.webp)

Bash is all you Need

Bash is what makes Claude Code so good.

Bash is a generic version for “code mode” or programmatic tool calling.

The bash tool allows you to:
- Store the results of tool calls to files, so you can search them.
- Store memory in files.
- Dynamically generate scripts and call them.
- Compose functionality, use unix primitives like tail, grep, cat, etc.
- Use existing powerful software like ffmpeg, libreoffice, etc.

# Fetch emails from this week, extract recipients, dedupe, enrich with
contact details
curl "api.gmail.com/messages?since=$(date -d '7 days ago' +%s)" \
  -H "Authorization: Bearer $TOKEN" | \
  jq -r '.messages[].to[]' | \
  sort -u > contacts_this_week.txt

# Now fetch full contact details for each
while read email; do
  curl "api.contacts.com/search?email=$email" \
    -H "Authorization: Bearer $TOKEN" >> contact_details.jsonl
  sleep 0.1  # rate limiting
done < contacts_this_week.txt

# Aggregate results
jq -s '.' contact_details.jsonl > final_contacts.json

# "Find all moments where the speaker says 'quarterly results' in this earnings call"

# Extract audio, transcribe with timestamps
ffmpeg -i earnings_call.mp4 -vn -acodec pcm_s16le audio.wav
whisper audio.wav --model medium --output_format json > transcript.json

# Find timestamps for keyword
jq -r '.segments[] | select(.text | contains("quarterly results")) |
  "\(.start) - \(.end): \(.text)"' transcript.json > moments.txt

# Create video clips for each moment (with 5 sec context)
jq -r '.segments[] | select(.text | contains("quarterly results")) |
  "\(.start - 5) \(.end + 5)"' transcript.json | \
  while read start end; do
    ffmpeg -i earnings_call.mp4 -ss $start -to $end \
      -c copy "clip_${start}.mp4"
  done

The central claim is that Bash is a general-purpose composition layer.
