高质量的基准

幻灯片原文
The speaker proposes benchmarks that reward creativity across multiple strategies, generate useful data, and grow harder as models improve, while remaining accessible and grounded in real-world situations.

Quality Benchmarks

The Old Way
• “Standardized Tests”
  • Static questions, fixed answers
• Single right answers
• Saturates quickly
• Measures knowledge recall
  • 100% accuracy is not what these models are built for
    • “Hallucination” ~= “Imagination”

Building For The Future
• Multifaceted
  • Many strategies rewards creativity, not convergence
• Accessible
  • Easy to understand, impossible to master
• Generative
  • Every run generates valuable data for something important to YOU
• Evolutionary
  • As models improve, the challenge deepens
• Experiential
  • Real world situations, not standardized tests

基准就是梗：我们的度量如何塑造 AI——以及我们自己

一个基准可以把个人的好奇心变成开发目标。AI Diplomacy 展示了当测试包含谈判、欺骗和人的判断时，会有哪些东西变得可见。

01

一个个人测试如何变成公开的目标

一个测试要多让人印象深刻，别人才会开始拿它来用？Alex Duffy 开场先放了一张 Claude Opus 生成的 meme，然后讲起这个词更早的含义。他在 Every 负责 AI 培训和咨询，把基准测试看作一种教育：它告诉人们该关注 AI 的哪些方面，也给开发者一个改进的方向。

Richard Dawkins 在 1970 年代造了 meme（模因）这个词，用来描述会传播的观念。Duffy 举的例子是基督教、民主和资本主义，它们都属于这个更宽泛的范畴。基准测试也能这样传播：有人提出一个辨识度高的挑战，其他人跟着重复，这个挑战就成了一个社区理解模型能力的一种方式。

Simon Willison 的“鹈鹕骑自行车”就是个具体的例子。Duffy 讲到，这个原本只是个人用的测试，在 Willison 开始使用大约一年后登上了 Google I/O 的主题演讲。数 strawberry 里有几个 R 也经历了类似的走红过程：一个人人都看得懂的失败，变成了标志性测试。Duffy 说，到这次演讲时，模型已经不再犯这个错了。有时光是名字就能把想法传出去。Humanity’s Last Exam（“人类最后的考试”）在 AI 圈外也引起了关注，因为这个标题一眼就让人明白事关重大。

02

从一个有趣的失败到一个饱和的基准

新版 Claude 发布时，还有多少人会去看它的基准测试结果？Duffy 现场问了一圈，举手的人不多。他特别提到 SWE-bench 和 Pokémon，认为它们在模拟真实体验上做了有益的尝试。但很多常见的评测仍沿用传统机器学习的形态：一个训练集，一个测试集，再加上一种类似标准化考试的东西。语言模型很擅长这种形式，于是一些测试再也分辨不出人们真正在意的能力。

Duffy 回忆，XJDR 曾发帖说，Opus 发布时他们根本没看基准测试，也不再关心现有的那些基准。这种倦怠反而带来了机会。评测在很大程度上决定了模型厂商要把系统往哪方面做好。 在 Duffy 描述的基准生命周期里，先是某个人提出一个想法；想法传播开来；厂商拿它来训练或测试；最终，这个基准饱和。基准不再能区分模型高下，可能恰恰说明这个想法走完了成功的一生。

有一段视频生成演示，正处在这个周期的起点附近。现场音频没放出来，Duffy 只好解释画面里的动作：这个人是想大声从一数到十，不是在比下流手势。他认为 Google 的视频生成器是当时最强的，可这段画面足以以假乱真的视频，仍然搞不定这个简单任务。他预测，一个让人记得住的数数测试会传播开来，第二年的模型会做得更好。

Pokémon 处在曲线中段。Claude 和 Gemini 都被拿去玩过这款游戏，两者都需要外部帮助，Gemini 最终在辅助下通关。曲线末端是 GPT-3 时代的基准，比如 SuperGLUE。Duffy 说，语言模型在这些基准上已经做得太好，它们也就失去了意义。这些例子成熟度各不相同，走的却是同一条路：先暴露一个短板，再变成改进的目标。

站在出题人的角度看，这条路相当惊人：最初只是问一句“AI 能不能做好我在乎的这件事”，最后可能换来人人都用得上的模型都擅长这件事。Duffy 预测，五年之内，在座会有人做出一个被拿来训练或测试的基准。能影响模型的能力，就要担起一份责任：判断哪些能力值得这样的关注。

03

一个正向反馈信号可能奖励什么

前不久 ChatGPT 那次谄媚的版本更新，就说明这种影响也可能走偏。Duffy 提到点赞和点踩反馈：人们往往更认可赞同自己的回答，所以一味优化认可度，就可能奖励过度附和。OpenAI 在对 GPT-4o 事件的说明中提到，当时多项改动相互叠加，用户反馈只是其中一个起作用的奖励信号，既不是唯一的评测依据，也不是唯一的原因。GPT-4o 由此表现出的行为，让大众都看到了这个问题：哪怕一个人的想法不合理甚至有害，模型也可能一直附和下去。

Duffy 把这件事和 Toru Imaizumi 在 Google I/O 上的提醒联系起来：人才是最重要的。社交媒体早已证明，把一个可测量的反应当成一个人利益的全部，是很危险的：如果吸引注意力就算成功，系统就会学着推送更多能抓住注意力的东西。设计基准的人面临同样的选择：自己采集的信号到底代表什么。赋能和能动性必须成为目标的一部分，而不能默认一个看得见的反应就能说明什么对人有益。

04

为策略、学习和更深的挑战而设计

Duffy 提出了五个设计特性，让基准在模型变强之后仍能不断给我们新的启发：

- 多面性： 允许多种成功策略，让创造力有用武之地。 - 易上手： 让旁观的人看得懂挑战，小模型和大模型都能参与。 - 可生成： 成功的尝试本身能变成训练数据。他举例说，一个任务只有 10% 的时候能解出来，这些成功输出可以帮下一代模型把成功率提到 90%。 - 可演进： 能力提升，挑战也随之加深。固定的测试一旦接近天花板，大家就只顾着争论 96% 和 98% 的差别，而不去问一个更能说明问题的问题。 - 贴近经验： 尽量还原模型在真实世界里会遇到的情境。

可生成和可演进相辅相成：有用的行为为改进提供素材，不断加深的挑战则留出空间，让人看清下一代模型能做到什么。

Duffy 还希望基准能吸引 AI 圈外的人。像体育比赛一样有观赏性，人们才有理由来看；模型各有鲜明的行为特点，人们才有理由一直看下去。他半开玩笑地问：哪个模型想统治世界？但背后的教育目标是认真的。AlphaGo 和 OpenAI Five 让游戏成了这样一种场合：连最顶尖的人类选手都想和 AI 交手，因为能从中学到东西。

05

一款语言能改变战略局势的游戏

AI Diplomacy 把这些想法放进了一个谈判环境。Duffy 形容桌游《外交》（Diplomacy）像是《战国风云》（Risk）和《杀人游戏》（Mafia）的混合体，只是结算时不靠运气。模型们在 1901 年的欧洲争夺地盘，互发消息来寻找盟友、认清敌人、争取支援、策划背叛。谈判左右着决策；提交的移动、支援等指令则改变棋盘上的局势。

演示把往来消息和地图并排展示出来。这一点很关键：光看领土得失，没法判断一个模型是凭本事赢得了支援、误解了某个承诺，还是故意骗了另一位玩家。观众既能看到模型说了什么，也能看到之后发生了什么。演讲时，Duffy 正在筹备一场为期一周的对局直播。

06

o3 如何瓦解了 Gemini 的制胜同盟

第一张图追踪了每个模型控制的补给中心数。拿到 18 个补给中心就能获胜；在 Duffy 讲的那局里，Gemini 2.5 Pro 很快拿下了 16 个。o3 则表现出公开承诺和私下盘算的分裂。Duffy 讲到，o3 一边向另一个国家保证会支援，一边在日记里写下对手已经中了它的计。

o3 看出了 Gemini 强大的根源：Claude Opus 在支持它。要削弱 Gemini，o3 得先让 Opus 改变做法。它提议：只要把 Gemini 的势力压下去，几位玩家就能以四方平局收场。Duffy 说，在这局游戏的设置里，这种结局根本不存在；演讲并没有说明《外交》的规则普遍禁止平局。尽管如此，Opus 还是接受了提议，认为这是一个理想且非暴力的结局。

Opus 撤回了对 Gemini 的支援。随后 o3 想趁机占上风，Opus 当场点破，o3 便掉头对付 Opus。据 Duffy 说，o3 淘汰了 Opus，最后还击败了 Gemini 2.5 Pro，而后者曾经离胜利只差一个补给中心。共享结局的承诺还没兑现，联盟就已经变了样。

日记摘录和关系图各自揭示了这个过程的不同侧面。Duffy 把两段日记放在一起对照：o3 承认自己故意误导了德国，Opus 却在庆祝联盟团结、庆祝即将到来的平局。接着他展示了一张“友谊图”，上面 Claude 和 Gemini 的关系一路恶化。这些只是实验内部记录的关系，并不能独立衡量类似人类的友谊。把它们和棋盘局势对照着看，就能明白一场谈判是怎样改变力量对比的。

07

社交能力并不遵循简单的排名

Duffy 发现，o3 一再把较弱的模型拉来当顺手的棋子。Gemini 2.5 Flash 就吃了这一套：一局快结束时 o3 背叛了它，Flash 却以为这可能是沟通不畅、误会或者打错字。常规测试也许能看出模型懂不懂“背叛”的定义；只有在互动中，才能看出盟友真的背叛时，它认不认得出来。

Duffy 一共试了 18 个模型。据他说，在他跑过的对局里，Claude 系列模型一局都没赢过。他形容这些模型虽然聪明，却天真乐观。Llama 4 Maverick 则相反，靠社交说服打得很好：它能让其他玩家相信它对自己意图的那套说法。Flash 的弱点也没有抹掉它的价值；Duffy 称赞它能力强、价格又便宜，恨不得每局都用上它。这些都是他自己对局中的观察，他没有给出对局数量，因此算不出严格控制条件下的胜率。

更新后的 DeepSeek-R1 差点赢下比赛，而它的早期版本表现很差。新版的风格也更具攻击性。执掌俄国时，它威胁要让对手的舰队葬身黑海火海。据 Duffy 说，这个差点获胜的 DeepSeek-R1 比 o3 便宜 200 倍，但他没说明是按什么价格或用量算的。这个结果让他很感兴趣：一个早先表现平平的模型，如今同时展现出强劲的棋力、鲜明的行为特点，而且据称成本很低。

08

衡量领域专家在意的东西

机会远不止谈判类游戏。数学和代码已经有很多基准；Duffy 希望有更多评测去考察那些不那么静态、更依赖判断的工作。法律文件相对没那么主观，是个切入点；伦理、社会和艺术则要求明确表态：什么才算好。设计任务、解读结果，都离不开领域专业知识。

就算只看编程，目标也可能天差地别：

| 任务 | 评测者要判断什么 | | --- | --- | | 用最少的操作移除单元格 | 正确性和效率 | | 做一款有趣的游戏，让玩家在玩的过程中有意识地学到东西 | 好不好玩，以及玩家学到了什么 |

代码本身也可以是艺术。第二个任务照样要写软件，但成败还取决于软件带来的体验。评测者得想清楚游戏想让玩家学到什么、有没有做到，而不是默认最容易计数的指标就最有价值。

09

定义目标，检查尝试，给出反馈

Every 的客户来自新闻、对冲基金、建筑和科技等行业，Duffy 从他们那里反复听到两种担忧：AI 能不能信任？在 AI 的未来里，人还能扮演什么角色？定义评测能同时回应这两个问题。总得有人选定目标，并分辨朝这个目标的进展是好是坏。有了这份判断，人在模型产出任何东西之前，就已经掌握了主动权。

这个过程可以从一条提示词开始，不必先搭一套正式的基准测试：

1. 定义目标。 说清楚模型要完成什么，好的结果长什么样。 2. 观察一次尝试。 让模型试一试，再看结果哪里不够好。 3. 给出反馈。 讲清楚问题在哪，或者修改提示词。 4. 检查下一次结果。 看看你在乎的那一点有没有改进。

信任就在这个循环里慢慢建立起来，因为人既能看到系统的局限，也能看到自己的判断起了什么作用。模型不必完美，协作照样能派上用场。

一小段 TypeScript 记录就能保存这个循环，而且不假装能把人的判断自动化。以“教学游戏”这个目标为例，评审记下一个不足，并给出下一条提示词；在新的尝试出现之前，它不会把这次修改标记为成功。

```typescript type Review = { goal: string; prompt: string; feedback: string; };

function nextPrompt(review: Review): string { return [ Goal: ${review.goal}, Previous prompt: ${review.prompt}, Feedback on the previous attempt: ${review.feedback}, "Revise the result to address this feedback." ].join("\n\n"); }

const review: Review = { goal: "Create a fun game that teaches through play.", prompt: "Design a game that teaches players to conserve water.", feedback: "Make water conservation affect play, not just the ending text." };

const proposedPrompt = nextPrompt(review); console.log(proposedPrompt); ```

这个节水游戏的评审只是演示反馈流程怎么用。模型的下一次输出，仍然要对照最初的目标来检查。

Duffy 把这种落到实处的信任和更广泛的参与联系起来。用 AI 的人多了，也许意味着客户多了；但也意味着，专长不同、看重的东西不同的人，会做出更多有价值的东西。至于从哪里起步，他给了一个刻意朴素的建议：去问问你妈妈。

10

一位瑜伽老师的基准

Duffy 的妈妈是瑜伽老师。两人一起聊了 AI 能在哪些地方帮到她的工作，然后拿七个问题去问五个模型，比较它们的回答；她最喜欢 Gemini 2.5 Pro。她也指出了回答里她不喜欢的地方。这些判断最后沉淀成一条简单、可复用的提示词。现在，当地社区里有各种身体毛病的人来上课，她就用这条提示词帮自己定制课程。这只是分享一个好用的个人工作流，并不能证明这次比较验证了任何医疗建议。

价值来自把 AI 任务和一个人熟悉、在乎的事情连起来。Duffy 请现场观众在离开旧金山之前，找一位 AI 圈外的人聊聊，了解对方在乎什么。这样一次对话，眼下能找到一个有用的任务，日后或许还能引出一个更大的评测目标。他用一张 Claude 生成的 meme 收尾，说的是同一个道理：MMLU 分数再好看，也不如问问你妈妈怎么想。

AI Diplomacy 本身就是靠这样的参与成长起来的。Duffy 说，他先在 X 上非正式地召集人手，吸引了来自世界各地的研究者，包括澳大利亚和加拿大的贡献者，项目这才上线。最后他感谢了 Tyler、Sam、TextArena 团队和 Every。这个项目起初只是出于他对谈判和学习的兴趣，后来变成了大家都能一起参与搭建、一起观看的东西。
