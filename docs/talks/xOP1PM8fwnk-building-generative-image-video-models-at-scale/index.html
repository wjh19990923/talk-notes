大规模构建生成式图像与视频模型

训练一个视觉生成器，意味着要选择压缩什么、如何去噪、把采样算力花在哪里，以及哪些控制手段能让人塑造结果。

对神经网络、张量和条件生成有基本了解会有帮助；文中会从基本原理建立对扩散和采样的直觉。

01

一个视觉生成器包含什么？

要大规模训练能生成图像和视频的模型，需要做些什么？神经网络只是答案的一部分。Sander Dieleman 自我介绍说，他是研究科学家，在 Google DeepMind 工作了十多年，所在的生成式媒体团队做出了 Veo、Nano Banana 等模型。他从扩散讲起：按他的说法，扩散是音视频生成的主流方法；语言建模的主流则是自回归。

工程决策贯穿整条链路：从数据整理和表示，到建模、架构和分布式训练，再到采样、蒸馏和控制。表示决定网络要学什么；采样决定网络的预测怎样变成成品；控制决定成品有没有用。Dieleman 在博客里详细讲了这些生成机制背后的直觉。

改进数据，回报可能比调模型、调优化器更高。 这和研究界一个常见的惯性相悖：大家都用同一个固定数据集，结果才好横向比较。可要做出能力强的生成模型，就得亲自检查、改进数据。Dieleman 觉得大家至今仍低估了数据整理，但他没有透露具体做法：这些做法正是模型之间拉开差距的地方，论文里也很少写。

02

让每个训练样本都易于处理

图像是二维像素网格，视频在这个网格上再加一个时间维度。早期扩散模型直接在像素上运算，但分辨率和时长一上去，这种表示很快就变得非常昂贵。Dieleman 举了个例子：一段 30 秒、1080p、每秒 30 帧的视频，光像素数据就有好几 GB，而这只是一条训练样本。具体占多少内存取决于数值精度，这还没算训练本身的开销。

现有的图像和视频编解码器，解决的是另一类压缩问题。JPEG 和常规视频格式优先追求存储紧凑，哪怕这样会掩盖生成模型需要的结构。更好的办法是自己训练一个压缩器，让它的输出依然便于建模。自编码器先把输入挤过一个紧凑的潜在瓶颈，再学着把它重建出来。

这样得到的流程分为三个独立步骤：

1. 训练自编码器。 编码器把图像或视频压缩成潜变量（latent），解码器学着把它重建出来。 2. 训练生成器。 先对训练样本编码，再在这些潜在表示上学习生成模型。这一阶段可以用自回归，也可以用扩散；Dieleman 说，在参数预算相同时，扩散生成的音视频质量通常略胜一筹。 3. 生成并解码。 采样一个新的潜在表示，再送进之前训练好的解码器，得到像素。

所以，生成器学的是压缩后样本的分布，解码器负责把结果还原成看得见的图像或视频。

03

压缩细节，同时保留网格结构

以一张 256×256 的 RGB 图像为例，编码后变成 32×32 的潜在网格。Dieleman 不太确定地说，这组尺寸对应最早的 Stable Diffusion；它们也确实符合该模型空间上 8 倍下采样的设定。关键要分清空间分辨率和张量总大小：潜在通道同样占内存。多出来的通道承载着直接缩小图像会丢掉的信息，包括一部分高频细节。压缩依然有损，但表示小了很多。

视频在时间维度上还有更多冗余。Dieleman 说，学习式压缩通常能把视频张量缩小约两个数量级。这是他给出的一般性观察，并不是某个特定编解码器或潜在配置下的压缩比。它的实际意义在于：一条训练样本是能装进内存，还是根本没法处理，往往就差这一步。

这类学习式压缩器有意保留了比 H.265 等编解码器更明显的结构。潜在表示仍是网格拓扑，只是尺度更粗，神经网络因此能利用空间关系。EQ-VAE 的一张可视化图直观展示了这一点：把各潜在通道的主成分映射成 RGB，得到的图里依然认得出动物。压缩主要作用在局部纹理和精细结构上，场景的整体布局仍然留给生成器使用。

04

为什么单次去噪预测是模糊的

表示变得好处理之后，下一个问题是怎么生成它。自回归把数据排成序列，逐个预测后续元素。这种顺序对语言很自然，但二维图像只能人为规定一个遍历顺序。扩散则定义一个破坏过程：逐步加噪，再学一个去噪器，预测怎样把破坏逆转回来。两种方法都是迭代地构建输出。

兔子的例子展示了破坏过程最先抹掉什么。加一点高斯噪声，胡须就难以分辨，但看轮廓仍认得出是兔子。噪声再多，整体结构最终也会消失。细节先消失、大结构后消失——等过程反向运行时，这个顺序就很关键。

为了讲清反向过程，Dieleman 把图像空间简化成一张二维示意图。真实的图像和视频都是高维对象，所以这张图只是几何上的辅助，不是它们所在空间的真实样貌。设 x₀ 是干净样本，xₜ 是它在破坏时刻 t 的加噪版本。生成时，采样器从噪声出发，最终到达某个类似 xₜ 的中间状态。去噪器再根据这个观测，预测出一张干净图像。

这个预测有歧义，因为破坏过程毁掉了信息：同一个带噪观测，可能来自许多不同的干净原图。去噪器对这些可能性取平均，结果就是模糊。讲反向过程的那页幻灯片把带噪的猫、模糊的预测和清晰的原图摆在一起对比。预测给出的是通往合理图像的方向，而不是一张可以直接拿来用的成品。 更有用的理解是：这张模糊的估计代表它周围一整片可能的原图。

05

迈一小步，再预测一次

如果一步跳到预测的干净图像，模糊也会原样保留。正确做法是朝它走一小段，再问一次去噪器。这和神经网络优化很像：更新方向只在局部有效，步子迈得太大，就会越出它适用的范围。区别在于走的是哪个空间：优化器改的是模型参数，扩散采样器改的是像素或潜变量的值。

许多采样算法接着会加一点新噪声，量比去噪时去掉的少。这是新的随机性，不是刚刚去掉的那份噪声。去噪器的预测并不完美，把这些误差一轮轮喂回去，误差就可能累积。新噪声能掩盖一部分错误，让轨迹更稳健。也有些采样器省掉这一步。

到了下一个状态 xₜ₋₁，图像的噪声又少了一点。去噪器拿到的信息更多，预测随之改变，可能的原图范围也缩小了。如此反复，歧义逐步消除，最终得到一个具体的样本。采样器能成功，靠的是不断修正局部预测，而不是相信第一次的估计。

06

为什么扩散模型由粗到细地生成

傅里叶分析能解释这套流程为什么特别适合视觉数据。Dieleman 取了四张 ImageNet 图像，分别做二维傅里叶变换。结果是复数，可以拆成幅度和相位。这里先不管相位，用径向平均把每个二维幅度谱概括成一条一维曲线。

在双对数坐标下，这些曲线近似直线，说明频率和频谱幅度之间是幂律关系。自然图像通常低频成分强、高频成分弱；Dieleman 认为视频大体也是如此。高斯噪声则不同，它的频谱在期望意义上是平的。把它加到图像上，较强的图像频率仍然看得见，较弱的就被淹没了。

所以，噪声越大，最先被盖住的是最高频，然后频率越来越低，直到图像结构完全无法分辨。把这个过程反过来，就是先建立低频结构，再补上高频细节。Dieleman 称之为频谱自回归（spectral autoregression）：这只是近似的类比，并非严格的自回归顺序。它让生成器先定下场景的大体语义，再填充细节；训练时也可以侧重感知上最重要的噪声水平，也就是最重要的尺度。

07

为空间和时间选择一种架构

去噪器的输入输出约定很简单：输入带噪图像，预测对应的干净图像。U-Net 最初为分割任务开发，天然适合图像修复这类保持空间维度的任务。早期的 Stable Diffusion 模型就用这种架构。Transformer 同样可行，而且和典型语言模型有个重要区别：去噪允许完全双向的注意力，不需要因果掩码。改用 Transformer，还能直接沿用语言模型积累下来的扩展（scaling）经验。

在视频上，自回归和扩散有几种组合方式：

| 方法 | 生成顺序 | |---|---| | 完全自回归 | 把高 × 宽 × 时间展平，逐 token 生成 | | 联合扩散 | 对整个时空体积一起加噪、去噪 | | 混合 | 按时间顺序逐帧生成，每帧内部用扩散 |

Dieleman 说，联合扩散是当今视频生成模型的常见做法。混合方案在实时生成中尤其有用，因为新帧必须跟着事件的发展一帧帧生成。他举了 Genie 作为这种折中方案的例子。

训练这些网络，最终不只是把一个 batch 拆到多个加速器上那么简单。数据并行把样本分到不同芯片上；模型并行则把模型本身拆开。Dieleman 说，这些视觉模型通常仍比同期的 LLM 小，但已经大到分片和通信不能忽视。他提到用 JAX 和 pjit 描述分片方式，让编译器减少芯片间通信。当前的 JAX 文档已弃用 pjit，改推 jax.jit；底层目标不变，仍是高效的分布式执行，但不保证得到全局最优的放置方案。

08

放大提示词的作用

采样还有一些选择，和去噪器架构无关。确定性采样器会把一个初始噪声样本对应到固定的输出，这对蒸馏很有用。随机采样器在过程中引入新的随机性，能抵御预测误差的累积。引导（guidance）又带来一个选择：用多样性换质量。按 Dieleman 的说法，引导越强，样本彼此越像，单个样本的质量却越高；扩散模型因此不必达到 LLM 的参数规模也能表现出色。引导同样适用于自回归模型，不过他发现它在扩散模型上效果格外明显。

引导的机制从对同一个带噪输入做两次预测开始。第一次不带文本提示词，第二次带上。描述兔子的提示词限定了哪些原图能解释这个观测，所以有条件的预测通常没那么模糊。真正有用的是两次预测之差。放大这个差值，就得到一个新的去噪方向，突出提示词带来的那部分信息。

把无条件预测记作 u，有条件预测记作 c，引导系数记作 s，组合方式如下：

``math \begin{aligned} \Delta &= c-u \\ \hat{x}_{0,\mathrm{guided}} &= u+s\Delta \end{aligned} ``

用 Python 和 JAX 写出来，张量运算非常简洁：

```python import jax.numpy as jnp

def guided_prediction( unconditional: jnp.ndarray, conditional: jnp.ndarray, scale: float, ) -> jnp.ndarray: delta = conditional - unconditional return unconditional + scale * delta ```

两个输入必须针对同一个带噪样本、同一个噪声水平，而且采用同一种预测参数化方式。按这种约定，scale=1 返回的就是有条件预测；取更大的值，则会越过它继续外推。采样器用组合后的预测做下一步更新，其余流程（包括可选的新噪声）照旧进行。按这里描述的引导方法，每个采样步要调用两次模型。

有引导和无引导的对比示例出自 OpenAI 2021 年的 GLIDE 论文，这是一个早期在像素空间上做的大规模扩散模型。从展示的对比看，引导降低了多样性，但让单张图像更贴合提示词。Dieleman 认为，引导在现代图像生成中实际上已是标配；要是去掉它，用户会惊讶于质量下滑之大。对只想要一张好用图像的用户来说，这点提升可能比保留所有可能输出的多样性更重要。

09

把轨迹蒸馏成更少的步数

这里的蒸馏主要指减少生成一个样本所需的网络前向次数，而不是把网络变小。采样过程会在像素或潜在空间里走出一条非线性轨迹。在每个点上，去噪器给出一个局部方向，也就是一条切线，告诉采样器下一步往哪走。用确定性采样器时，某个初始噪声样本会沿固定路径走向某个特定输出。

有了这条路径，就可以换一个学习目标：直接预测路径的终点。一致性模型（consistency models）提供了一种办法，从扩散模型中蒸馏出这种终点预测，有望用一次直接跳跃取代许多次局部更新。这是减少采样步数的几种方法之一。

只跳一步，对网络的要求很高。Dieleman 打了个比方：这相当于让一次前向完成原本分摊在约五十次前向里的工作。折中的办法是在轨迹上更短的区间内学习终点预测，保留几步生成——他的例子里是三步。这些步数只是用来说明质量与算力的取舍，并非实测的加速比。区间越短，每次预测要压缩进去的工作就越少。

10

给用户语言之外的控制手段

生成器有多大用处，取决于人能在多大程度上左右它的输出。文本提示词描述场景很方便，但碰到某些精确需求就显得笨拙。想把自己放进生成的视频里，直接给一张照片或一段短视频，比事无巨细地描述长相直接得多。视频还需要显式控制镜头运动、事件速度和事件发生的时间点。这些信号都要用适合被控对象的方式来表示。

训练上的问题是：这些信号什么时候引入。大多数预训练样本可能没有专门的镜头或时间标注。一种做法是预训练时只用文本做条件，到后训练阶段再加入其他控制。这个阶段还可以通过强化学习或直接偏好优化融入人类偏好。模型先学到广泛的视觉分布；之后的训练再决定用户怎样操控它，以及系统偏向哪些输出。

11

为什么模型会形成一种风格——以及引导在哪里有帮助

观众提问先从质量与多样性取舍的一个明显后果说起：像 Nano Banana 这样的模型有一眼可辨的风格，是因为引导吗？Dieleman 认为引导是部分原因，但他猜后训练的作用更大。预训练建模的是广泛的图像分布；后训练则从中挑出带有鲜明取向的一部分。

引导也可能带来更具体的瑕疵。Dieleman 指出，饱和度过高往往说明引导系数设得太大。有条件与无条件预测之差在各个噪声水平下都会被放大，所以同一个系数在轨迹不同阶段的效果也不同。他介绍了一些工作：开头和结尾不用引导，中间加强引导。可见，除了给每一步选同一个系数，还可以用引导调度（guidance schedule）来处理这种取舍。

在文本扩散中，提示词同样可以充当条件信号，所以同样的引导原理也适用。至于效果如何，是另一回事。Dieleman 的直觉是，条件信号和输出之间有语义落差时，引导才更有用：文本描述提供高层含义，图像则包含细致的视觉呈现。分割掩码更贴近像素的空间结构，按他的经验，从引导中获益较少。他也用同样的直觉解释，为什么语言生成（包括自回归模型）较少用引导。

12

框架选择与更多采样的局限

有人问 JAX 是否比 PyTorch 更适合做分片。Dieleman 先说明了前提：他在 Google 待了十多年，几乎没怎么上手用过 PyTorch。他认为 JAX 的设计考虑之一是让 TPU 好用，尤其是在通过高速互联连接的多芯片上。PyTorch 同样支持并行和分片，这些能力并非 JAX 独有。他讲的是设计侧重和个人经验，不是性能对比测试的结果。

去噪步数越多，结果就越好吗？到一定程度为止。有限次采样更新，是用分段线性路径去近似一条非线性轨迹。如果更新偏离真实轨迹太远，样本质量就会下降。步数更多、步子更小，可以减少这种近似误差，但收益有上限。另一条路是从一开始就学出更直的轨迹：rectified flow 和 Reflow 的目标，就是让更少、更粗的更新也能准确生成。

13

注入正确的信号，选择正确的采样器

有个关于镜头控制的问题：能不能用模拟器提供已知的相机参数来训练？Dieleman 没有证实存在这样的流程：他不能透露内部做法，也没有直接参与负责这项工作的能力团队。一般性的设计问题是：先为这种控制找到有语义意义的表示，再决定怎样把它送进 Transformer。

有两种具体的接入方式：

- 额外 token： 把条件信息作为额外的 token 加进去，供模型做注意力。 - 广播条件： 让每个 token 都能拿到这个信号。扩散的噪声水平通常就是这样提供的，而不是单独用一个额外 token 来表示。

信号起什么作用，就决定了该用哪种接入方式。像当前噪声水平这样的全局属性，需要影响整个表示的处理过程。Dieleman 还提到了另一种条件注入方法，但没有展开。

最后一个问题回到注入新噪声：不加新噪声，生成能否是确定性的？同一个去噪器既能做随机采样，也能做完全确定性的采样。在数据分布和噪声分布之间双向转换，或者训练学生模型复现教师模型的轨迹时，确定性轨迹尤其有用。这里讨论的一致性蒸馏方法用的是确定性的教师模型；但并非所有训练一致性模型的方法都有这个要求。Dieleman 最后提到，YouTube 上有这场演讲的加长版。实践上要记住的区别是：训练好一个去噪器后，有好几种生成流程可选，它们在稳健性、可逆性和推理成本上各有不同。
