发布 AI Engineer Network

在首届 AI Engineer 峰会上，Network 为大会应用加入了基于 LLM 的参会者匹配功能，以参会者资料中描述的问题作为建立联系的起点。

01

会场里一个正在形成的生态

是哪些人聚到一起，来打造 AI 工程这个新兴领域？AI Engineer Summit 2023 开幕，接下来两天由创始人和工程师轮番登台，Swyx 稍后会交代技术背景。Benjamin Dunphy 先环顾全场。生态变化有多快，AutoGPT 就是现成的例子：几个月前它还只是个开源项目，如今已是本届峰会的首席赞助商。Dunphy 称它是史上增长最快的开源项目，但没说按什么指标算、跟哪个时期比；他还预告 Toran 稍后会有新发布。

Supabase 则是另一种组合：一边是活泼的社交媒体和产品发布，一边是数据库。Dunphy 认为它的数据库好用又可靠，这跟开源分不开。他说，这家公司本来规定不赞助活动，这次却成了钻石赞助商；接着他请 Paul 和 Ant 回头告诉他，改了规定之后效果如何。

Fixie 让这些可能性更具体。Dunphy 想去它的展台问问那个助手，能不能看到他今天穿了什么，再给点换装建议；他还给这个助手起了个外号叫 Derek。这种视觉交互目前只是设想。如果视觉功能还没上线，他愿意把 Matt 和 Ben 介绍给 Logan Kilpatrick，看能不能提前试用 Vision API。这是 2023 年 10 月的展望：OpenAI 在 11 月公开发布了 vision API，GPT-4 Turbo 可以通过 gpt-4-vision-preview 输入图像。

02

从投资到对话

Dunphy 认为，微软对 OpenAI 的投资推动了这场运动的商业化。另外，微软后来发布的一份报告称，2019–23 年累计投入 130 亿美元；而当时的合作公告只说是一笔为期多年、规模达数十亿美元的投资。对在场的创始人来说，眼前的机会是去 Carmel 厅找 Microsoft for Startups 的代表聊聊，从观众席后方穿过电梯就到。GitHub 展台就在旁边，有 Copilot 的问题可以去那里问。这些只是帮忙引荐团队，并不承诺给初创公司投钱。

Cloudflare 收到了一句迟到的生日祝福，Dunphy 开玩笑说它接下来要经历一些变化。它的展台在 Carmel 厅，紧挨着微软，就在电梯对面。接着他介绍了 Alessio Fanelli——Latent Space Podcast 里负责风投的那一半。Dunphy 说，他的技术功底一点不输 Swyx。也许这些演讲能让 Fanelli 重新下场创业，不过 Dunphy 建议他这回做软件，硬件还是留给专家吧。

03

已经有用的对话能变得更有用吗？

Dunphy 介绍，首届峰会的观众是精挑细选的 500 人。他们要么是在生产环境里试水 AI 的资深软件工程师，要么是在做 AI 增强或 AI 原生应用和公司的创始人。大家经历相近，见面时就更有话聊：身边的人多半也在琢磨类似的实际问题。他还向直播观众致意，请他们关注第二天的开场主题演讲，届时会宣布 2024 年扩大参与的消息。

会议本身已经替大家做了一部分“找对人”的工作。它把世界各地的专家聚到一个细分主题下，很多对话不用谁牵线就已经有价值。下一个问题是：这么多专家聚在一起，能不能促成更好的连接？共同兴趣让对话有的可聊；把问题说清楚，连接才有了目的。

04

一个个人资料问题变成了匹配的基础

Network 应用先把参会者在手机上最需要的实用信息放进来：会议日程、完整的展商合作伙伴名单、其他活动信息，还有步行可达的餐厅、酒吧和咖啡馆推荐。在这个活动助手的基础上，Dunphy 宣布新增 AI 增强的参会者匹配功能。

这个功能叫 Generative Matching Algorithm（生成式匹配算法），简称 GMA。Dunphy 对这个名字的解释很直白：用 LLM 帮参会者找到合适的人。宣布的用法也很简单：

1. 在 Network 个人资料里写下你想解决的问题。 2. GMA 以你写下的问题为依据，为你匹配。 3. 和系统判断能帮上忙的人建立联系。

这里提到的实质性输入只有“问题”这一栏。发布时没有说明用了什么模型、提示词和排序方法，也没有说怎么评测匹配质量。

Dunphy 请参会者去会议的 Network 下载页安装应用。上线初期，匹配只面向本届峰会的现场参会者。这就划定了能匹配到的人群；不过这款应用的长远目标并不止于这一场活动。

05

把应用和匹配算法开放给其他活动

最后一项发布把范围扩大了：Dunphy 宣布，活动应用和匹配算法都将开源。目标是让世界各地的活动参会者都能用上简单又强大的移动端体验，再由匹配功能帮他们找到彼此。

致谢名单按应用、匹配和基础设施分工列出：

- 移动应用： Simon Sturmer，首席工程师。 - 生成式匹配算法： Suizette Steller。 - 身份认证： Descope。 - 数据库与向量： Supabase 和 pgvector。

Dunphy 请参会者去外面找合作伙伴聊聊 pgvector。列出它，交代了一部分基础设施；但发布时没有解释向量在 GMA 做匹配决策时起什么作用。

感谢完开发者和合作伙伴，Dunphy 宣布代码仓库当天就能通过 Network 落地页和 GitHub 获取。结尾的幻灯片给出了地址：aiDotEngineer/Network。这次开源让这个想法走出了峰会：其他活动也能提供同样的移动端体验，帮参与者围绕各自带来的问题互相结识。

延伸阅读

  • Network source repository — Source repository for the mobile event application and its attendee-matching project.
  • AI Engineer Summit 2023 — Historical event page with the program, speakers, workshops, venue, and presenting organizations.
  • pgvector — Postgres extension for storing vectors and performing similarity searches, with installation and SQL examples.
  • Using pgvector with Supabase — Current guide to enabling pgvector and storing embeddings in a Supabase database.
  • Descope authentication quickstart — Current starting guide for adding authentication with Descope Flows or SDKs.
  • OpenAI's November 2023 vision API announcement — DevDay announcement introducing GPT-4 Turbo image inputs through the Chat Completions API.
