LLM 知识库：实用指南

从一个装满粗糙 Markdown 笔记的文件夹开始，然后用智能体技能添加链接、构建专题 wiki、安排定期维护，并生成你所掌握知识的各种视图。

对 Markdown 文件和 AI 编程智能体有基本了解会有帮助；不需要现成的 Obsidian 配置。

01

从那些你本来就会丢掉的笔记开始

How do you turn a disorganized Apple Notes folder into something you can actually navigate—and rediscover ideas you have forgotten? Ben Holmes, who introduces himself as Developer Relations Lead at Warp, starts with that familiar problem. Even adopting a dedicated notebook such as Obsidian does not guarantee that organizing it becomes a regular habit. The useful starting point is a place to capture thoughts, including material developed with LLMs, without first deciding where everything belongs.

The storage layer in this demonstration is simply a folder of Markdown files. Holmes writes and browses them in Hubble, his own notes app, but the same starting point works with Obsidian, Warp or another Markdown viewer. Enrichment adds category tags and links between related notes, making them easier for both people and agents to find. A wiki then organizes sources, people and concepts into browsable entries. Finally, an agent with access to the files can generate HTML visualizations of their relationships. Each layer builds on the notes underneath it.

02

收集足够多的原始素材

The first improvement is to make capture easier than opening a note and typing. Voice dictation can be awkward around coworkers, but it removes much of the effort of getting a thought down. Holmes estimates dictation at about 200 words per minute and expects it to outpace typing for most people. Treat that as his estimate, rather than a measured average for composing notes.

Wispr Flow is the familiar subscription example, but a subscription is not essential. Holmes highlights Handy, an open-source dictation tool that runs a local model on the device. This makes speech capture a capability you can add to your existing writing environment.

His own choice is VoiceInk. Holmes tentatively recalls a roughly $20 lifetime fee for updates; the pricing page checked on August 28, 2026 lists $29 for one Mac with lifetime access and updates. He also describes using a mobile app. In the desktop demonstration, holding an Option or Function shortcut starts dictation, and the output arrives as punctuated sentences and paragraphs. The recording cuts off a little at the end of the dictated passage, but the formatting is visible.

The longer example is a reflection dictated after listening to Acquired's episode about the founding of Walt Disney. What appears as several paragraphs began as one continuous transcription. Holmes uses the same approach on his phone and computer to collect raw notes. The important input to later wiki generation is plentiful source material, not immaculate formatting: a rambling reflection, a meeting transcript or observations after reading a research passage can all give an agent something useful to work with. Capture the thought while it is available; organization can follow.

03

把信息补全变成一个可重复的技能

A second podcast note, this time about Ferrari's founding, shows what enrichment adds. The central text still reads like a dictated reflection. Around it are tags identifying the material as a podcast and connecting it to focus areas, a source URL found by the agent, an enrichment timestamp and links to related podcast notes. The note remains recognizable, but it now has routes into and out of the rest of the notebook.

Holmes packages the operation in an agent skill called enrich note. Its instructions make the recurring decisions explicit:

1. Record the enrichment time. A later agent can recognize that an earlier pass has already happened. 2. Choose tags from a shared reference folder. This supplies a concrete vocabulary instead of letting each pass invent its own categories. Holmes explicitly asks Claude to resist creating tags, while allowing the list to grow when a real pattern warrants it. 3. Research the source. Use web tools to locate the original material; Holmes suggests Exa when a harness needs search capability. 4. Find related notes. Use file operations and key-term searches, then append links to those notes at the bottom.

The shared vocabulary matters because tagging is useful only when related notes converge on the same categories.

A compact Markdown instruction file can express that contract:

```markdown # Enrich note

Enrich the supplied Markdown note while retaining its original text.

- Record when this enrichment pass occurred. - Read the tag vocabulary in the reference folder. - Prefer existing tags. Add a new tag only when a recurring pattern justifies extending the shared vocabulary. - Use web search to locate the original source and add its link. - Search the notebook for related terms and ideas. - Append links to relevant notes in a Related notes section. ```
